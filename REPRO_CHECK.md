iso-energy sweep, the cross-dataset transfer, the Theorem 1/3 checks, and refitting the synthetic model. Their numbers
are regenerated by `p1_report.py` from the committed tables.

# Release `v1.0.1-tdsc-submission` (2026-10-14)

The check of the pushed tag at `75011ca` from an anonymous clone, in a fresh virtual environment with only
`pip install -r requirements.txt`, failed: `code/virat_scores.py` imported OpenCV at module level, every corpus loader
imports that module, and `requirements.txt` did not list OpenCV (the machine of the checks above had it preinstalled).
`v1.0.1-tdsc-submission` imports OpenCV only inside the two functions that read raw VIRAT videos and lists
`opencv-python-headless==4.10.0.84` in `requirements.txt` for that purpose (see `CHANGELOG.md`). No data, result
table or number changed: `results/numbers.json` keeps the SHA-256 above, and every C121 array is byte-identical.
The earlier tag stays published unchanged. The anonymous check of `v1.0.1-tdsc-submission` is recorded in the paper's
submission records.
