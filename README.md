# Skip-pattern side channels of content-aware camera gating

Code, preregistration, derived data, measured hardware traces and every result table behind the paper

> D. Lam Quoc, **When Skipping Speaks: Event Leakage through Content-Aware Gate Schedules, a Latency–Privacy
> Impossibility, and the Case for Periodic Gating** (submitted to IEEE Transactions on Dependable and Secure Computing).

Every number printed in the paper is a key of [`results/numbers.json`](results/numbers.json), generated by
`code/p1_report.py` from the tables in `results/`. The manuscript reads them through an auto-generated `numbers.tex`;
no number is typed by hand.

## Layout

|---|---|

All paths and constants are in `code/config.yaml`. |
| `code/real_trace/` | Real-plug validation: ESP32-S3 replay firmware (`fw_replay/`, Arduino), INA219 diagnostic sketch (`fw_diag/`), schedule generator, serial dump tool, alignment/calibration (`align.py`) and the attacks on the measured trace (`attack_real.py`). |
| `results/` | All derived tables (`P0_*`, `P1_*`, `P1b_*`, `P2_*`), figures and `numbers.json`. |
| `results/real_trace/` | Measured trace: raw device dump (`raw/20261013T161503Z/`, with `dump_manifest.json` holding the SHA-256 of every file), aligned traces, calibration (`calib.json`), attack and MI tables, `real_numbers.json`. |
| `data/_derived/39/c121/` | Per-frame derived files for the 121 C121 videos, **without content scores**: open schedule of the deployed gate G3 (`a_g3`), ground-truth event indicator (`e`), validity flag (`valid`); `index.csv` holds the logged open count and the SHA-256 of every array. |

## Data

* **C121** (CDnet 2014, LASIESTA, BMC; 121 videos). Released here without scores (`data/_derived/39/c121/`): the
  deployed gate's open schedule and the event indicator of every frame. With the release alone (the default when
  `CFS_PROCESSED_DIR` is unset), the code evaluates the deployed gate G3, the periodic gates G4 and the real-plug
  validation. The per-frame content scores (`frame_scores.parquet`, with `events_gated.csv` and
  `activation_by_video.csv`, from the pipeline of the author's IEEE IoT-J article on certifiable frame skipping,
  DOI 10.1109/JIOT.2026.3740931) are available from the author on request; `scripts/regenerate_scores.md` records how
  they were produced. With them, set `CFS_PROCESSED_DIR` to their folder. Everything else on C121 **requires scores**:
  the threshold families G1/G2, the rate-limited and randomized-response gates G5–G7, the presence attacker on G3
  (trained on the G1 thresholds), the observer sweep, the iso-energy sweep (`rho_sweep.py`), the cross-dataset
  transfer, Theorem 1/3 checks on C121 and refitting the synthetic model.
* **VIRAT**: the derived files in `data/_derived/39/virat/` are enough for every VIRAT result. Set
  `THS_DATASETS=<this repository>/data` (or leave it unset: the default is `data/` in this repository). Re-scoring the
  raw videos additionally needs the VIRAT videos, the DIVA annotations and the ASMAG+ gate sources (`virat_scores.py`).
* **Synthetic corpora** are generated by `code/data_sparse.py` from the fitted model committed in `results/`.

## Reproduce

Python 3.11; `pip install -r requirements.txt`.

```bash
cd code
# numbers.json (and the figures) from the result tables
python p1_report.py
# real-plug validation from the raw device dump (about 15 min on a laptop CPU)
python real_trace/align.py
python real_trace/attack_real.py
python p1_report.py            # merges results/real_trace/real_numbers.json into numbers.json (keys real.*)
# full experiment grid (hours): attacks per corpus, then merge
python attacks.py --corpus C121 VIRAT SYN_pi0.02 SYN_pi0.05 SYN_pi0.1 SYN_pi0.2 SYN_pi0.5
python attacks.py --cross --merge
python verify_bounds.py thm2 thm1 thm3 thm3seeds --seed 42
python rho_sweep.py                      # post hoc low-rate sweep
python data_sparse.py v2 && python syn_v2.py && python verify_bounds.py thm2v2 --seed 42   # post hoc SYN v2
```

Without scores, `python repro_release.py` (about 1 min) recomputes from the C121 release every G3 and G4 row of the
MI, attack and localization tables (MI of G3 and G4 P = 2 … 30; attackers and onset localization on G4 P = 5;
localization on G3) and compares them with the committed tables. `REPRO_CHECK.md` records both checks from a fresh
clone: the first block above, and `repro_release.py`.

### Hardware (real-plug validation)
ESP32-S3 board (16 MB flash, 8 MB PSRAM), INA219 breakout (0.1 Ω shunt) on I²C SDA = GPIO8, SCL = GPIO9, address 0x40,
shunt in series with the board's 5-V supply. Build with arduino-cli and the esp32 core 3.3.11
(`esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi`, partition table `fw_replay/partitions.csv`, LittleFS image of
`fw_replay/data/` at 0x310000). `make_replay_schedules.py` regenerates the schedules and the config;
`dump_trace.py --cmd ARM` arms a run, which starts at the next boot only when the shunt carries the board current.
